Panduan Khatam Al-Qur'an
========================

Panduan ini digunakan untuk mengkhatamkan Al-Qur'an dengan pembagian lima (5) kali baca per hari. Pembagian ini biasa dipakai saat bulan Ramadan, misal satu hari satu juz dan bacanya tiap waktu salat (dari Magrib hingga Asar sesuai penanggalan Hijriah).

Selain itu, jumlah khatam dan jumlah hari bisa diatur sehingga panduan dapat sesuai dengan keperluan/target yang diinginkan.
